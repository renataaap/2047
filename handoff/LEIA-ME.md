# Kit para continuar no Claude

1. Leia RELATORIO_PARA_CLAUDE.md.
2. Cole PROMPT_MESTRE_PARA_CLAUDE.md numa conversa com Claude ou abra no Claude Code.
3. Forneça acesso ao código privado https://github.com/renataaap/2047 (ou clone local).
4. Siga INSTRUCOES_TEXTURAS_PARA_CLAUDE.md para baixar/importar as imagens reais.

Este ZIP contém documentos e catálogos. NÃO contém o código do jogo, os modelos binários, partidas, credenciais ou imagens de textura. O código e os três carros integrados estão no repositório. Os ZIPs brutos anteriores precisam ser reenviados ao Claude quando necessários. Os links relativos dos relatórios referem-se ao checkout completo.

Base de implementação: 0.5.1 / 308f8df. Zero Poly Haven instalado. Os dados de testes no relatório são resultados anteriores documentados, não testes novos executados pelo Claude.
